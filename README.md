# Task 2 - To-Do List Web Application

## Overview

This project is a simple and interactive To-Do List Web Application built using **HTML, CSS, and Vanilla JavaScript**. The application allows users to manage their daily tasks efficiently by adding, completing, editing, and deleting tasks. All tasks are stored in the browser's Local Storage, ensuring that data remains available even after refreshing the page.

## Features

* Add new tasks dynamically.
* Mark tasks as completed or incomplete.
* Delete individual tasks.
* Edit tasks by double-clicking on them.
* Assign priority levels (Low, Medium, High).
* Clear all tasks with confirmation.
* Task counter displaying remaining tasks.
* Data persistence using Local Storage.
* Add tasks quickly using the Enter key.
* Instant UI updates without page reload.

## Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript (ES6)
* Local Storage API
